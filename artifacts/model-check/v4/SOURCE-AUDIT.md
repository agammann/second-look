## Remaining limits

V4 improves some contextual coverage and useful emptiness, while the larger ceiling can increase irrelevant context. Alternative/demonstration omissions and routine generic clarifications remain. The prompt still sometimes selects an incompatible scope question for an empty result; fail-closed validation prevents displaying it. Full seller text and the buyer's independent review remain essential. Real PayPal sandbox and final rendered-browser checks are separate gates. This audit changes no source or first-run data and recommends no additional tuning within these evaluated cases.
